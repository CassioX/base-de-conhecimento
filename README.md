# 📚 Base de Conhecimento de Suporte Técnico

Artigos, procedimentos e modelos que escrevi para padronizar o atendimento de suporte. Cada artigo segue a mesma estrutura: **sintoma → causas prováveis → diagnóstico passo a passo → solução → quando escalar**.

Documentar bem é uma das habilidades mais importantes do suporte: reduz o tempo de resolução, ajuda colegas no próximo atendimento e permite que o usuário resolva problemas simples sozinho.
